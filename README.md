# Boss Astra

A Codex skill for coordinating work: Astra handles planning and final validation,
while Luna and Sol take on bounded tasks when delegation helps.

## Install

Copy these files into `~/.agents/skills/boss-astra/`:

- [SKILL.md](SKILL.md)
- [LICENSE](LICENSE)
- [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)

## Use

```text
Use $boss-astra to plan and implement this task.
```
